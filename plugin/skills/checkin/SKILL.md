# /checkin — 월 근태를 노무대장 양식에 채우기

사용자가 준 달: `$ARGUMENTS`

## 순서

1. **달을 `YYYY-MM`으로 정한다.** "11월"처럼 연도가 없으면 오늘 기준으로 가장 가까운 지난(또는 이번) 해당 월로 본다. "지난달"·"이번 달"도 오늘 날짜로 계산한다. 인자가 없으면 이번 달이다. 어느 해인지 정말 애매할 때만 묻는다.

2. **스크립트를 실행한다.** 근태를 직접 읽어 옮겨 적지 않는다(한 달 치가 매우 길고, 손으로 옮기면 틀린다).

   ```bash
   python3 -I "${CLAUDE_PLUGIN_ROOT}/scripts/fill_ledger.py" --month YYYY-MM
   ```

   - 양식 기본 위치: `~/.config/check-check/template.xlsx`. 사용자가 다른 양식 파일을 주면 `--template <경로>`.
   - 결과 기본 위치: `~/Downloads/YY년M월노무대장_checkcheck.xlsx`. 다른 곳을 원하면 `--out <경로>`.
   - 접속 토큰은 스크립트가 `~/.config/check-check/mcp-token.txt`(또는 환경변수 `CHECK_CHECK_MCP_TOKEN`)에서 읽는다. **토큰을 출력하거나 대화에 적지 않는다.**

3. **결과를 그대로 전한다.** 스크립트가 출력하는 요약(JSON)을 보고 다음을 알려 준다.
   - 만든 파일 경로, 채운 근로자 수와 출퇴근 건수
   - `unmatched_in_app`: 앱에는 근태가 있는데 양식에 행이 없는 근로자 → 양식에 행을 추가해야 한다고 알린다
   - `no_records_in_template`: 양식에는 있는데 그 달 근태가 없는 근로자
   - `missing_check_out`: 퇴근 기록이 없는 날 → 퇴근 칸이 비어 있으니 앱에서 퇴근을 입력한 뒤 다시 실행하라고 알린다

## 알아둘 것

- 스크립트는 '전체' 시트의 **연·월 칸과 출근·퇴근 칸만** 바꾼다. 공수·연장·수당·공제는 양식의 수식이 계산하므로, **엑셀에서 파일을 열어야 숫자가 갱신된다.**
- 넣는 시각은 타각 보정이 적용된 "인정 시각"이다(앱 화면의 계산과 같은 기준).
- 기본급·식대 같은 수당 칸, 가불·숙소료 등 손으로 넣는 칸은 양식에 있던 값 그대로 남는다. 달이 바뀌면 사용자가 확인해야 한다고 한 줄로 알린다.
- 양식 파일에는 근로자 개인정보가 들어 있다. 내용을 대화에 옮겨 적거나 외부로 보내지 않는다.
- 오류가 나면 메시지를 그대로 전하고 원인을 설명한다(양식 없음, 토큰 없음, 401 등). 양식을 직접 고쳐서 우회하지 않는다.
